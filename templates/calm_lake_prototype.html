THE GOVERNING CONSTRAINT, and it decides most of what follows: do not beautify an unproven information architecture. Everything here is neutral gray on purpose (see calm_lake.css's ramp, which names the tokens.css token each gray is standing in for). If this layout only reads as calm once it is coloured, it is not calm - it is decorated, and the colour pass would be hiding that rather than revealing it. THE TEST THIS PAGE HAS TO PASS: a Product Owner opening it cold, with no explanation, can point at the project, the active object, the disturbance, the evidence path, and the available action. Everything in this file is subordinate to that. Four states, one document. Nothing is a separate page, because the claim being tested is that they are one surface: 1. BASE header + viewport + verb bar. Nothing else. 2. DISTURBED a closing-window banner, and only for a closing window. 3. DEPTH the "Why?" sheet - basis, what changed, horizon, show. 4. COMPOSER Ask, with the current selection already bound. WHY THIS IS A STANDALONE DOCUMENT and does not extend base.html: base.html IS the chrome - 2,436 lines of it, carrying the menu bar that 30 of pdf_viewer.js's getElementById calls resolve against. A prototype of a chrome-less surface cannot be built by extending the chrome and hiding it; that would prove nothing about whether the surface stands on its own. It cannot extend panel_shell.html either, whose own comment scopes it to iframe-embedded Display divisions. The cost - a duplicated head block - is accepted, and is exactly what makes this prototype unable to regress any existing page. NO INLINE style ATTRIBUTES ANYWHERE. app.py's CSP sets `default-src 'self'` with no style-src directive, so a parsed inline style attribute is refused.
