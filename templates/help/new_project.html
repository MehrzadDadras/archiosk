New Project

Project name

Use the project name your team will recognize. Project names must be unique. If no name is entered, Archiosk derives one from the selected file or folder; a duplicate name is refused.

Acronym

Use 3 or 4 letters. The acronym becomes the short project identity used in references such as ABCD-T014.

You can accept the acronym derived from the project name or type your own. After project work is filed under it, the acronym persists so existing references do not change.
