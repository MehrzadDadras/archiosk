# Bounded Turnstile source missions

Owner mapping: external_research and external_intelligence_airlock EXTEND_EXISTING;
CaseWorkspaceStore.retain_public_reference EXISTING_EQUIVALENT. No new durable
primitive, evidence store, router or comparison engine.

HTTP success is not content validation. The existing extractor excludes scripts,
styles, navigation and shell fallback text. Requested identity and provisions must
be present. Shells, transport refusals and ambiguous content have separate states.
Substantive content never establishes project applicability, authority or currentness.

The Product Owner-authorized Turnstile missions are fixed URLs: Ontario's adopting
regulation API, Ontario's official 2024 Compendium PDF, Ontario Fire Code API, and
the identified TSS 3000CA product page. The product is a candidate example, not a
selected project model or regulatory authority. No public-precedent mission or
arbitrary URL retrieval is authorized. General Composer keyword search is unchanged.

Original bytes, extracted regions, publisher metadata and validation outcome are
retained through the existing public-reference path, always EXTERNAL_REFERENCE
and unvalidated. PDF page numbers are physical 1-based pages; printed labels remain
in extracted text. Retrieval time does not establish publication/currentness.
The eight existing Turnstile investigations remain unchanged until explicit rerun.

Regression: tests/test_turnstile_research_validation.py, existing Airlock and
candidate-reference tests. No new visible component is introduced.
