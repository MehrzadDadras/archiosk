# Shared role composition and Capital Alignment Brief

This increment reuses CaseWorkspaceStore's AnalysisRun and existing
cross_modal_investigation.cover_requirements. It does not introduce an investment
engine or separate configuration store.

The attention UI selects current role propositions for one opportunity and one
retained matching execution per candidate. All executions must belong to the same
attention scope, context and temporal query. Each must explicitly examine every
selected role, including absent candidate evidence. Role propositions use the
existing typed TOKEN_SET contract with property key role. Financial amounts
cannot enter this coverage operation.

Optional individual role predicates may supply collective coverage. Mandatory
candidate predicates must match: a failure, unresolved premise or incomparable
constraint excludes that candidate. Other partners cannot erase it. Obligation
designations must agree across candidate comparisons. Changed, rejected,
superseded or unavailable premises exclude their historical matching execution
until explicitly re-evaluated.

The existing exhaustive set solver returns minimum coverage configurations,
missing roles and bounded alternatives. The UI exposes per-candidate coverage,
overlaps, exclusions, inputs and runtime invocation. This is not an entity
ranking. Capacity allocation, compatibility, monetary summation and financing
closure remain unresolved. Actual factual configuration remains UNRESOLVED even
when the conditional coverage model matches.

The existing render_professional_review owner now renders professional reviews,
matching and role composition through one WorkProduct/section publisher. Capital
results become draft Capital Alignment Briefs; other contexts become alignment
reviews. The DOCX export is the existing work_product_export path. Sections carry
the actual retained matches, attention, provenance, claim review state, unresolved
factors and next investigations. Rendering never re-runs matching or composition,
approves a fit, contacts an investor or overwrites an original result. Changed
premises surface REVIEW_REQUIRED; missing citations refuse publication before a
new work product is created.

Survey Evaluation adds eight matching games: conditional fit, partial evidence,
mandatory sector failure despite capital fit, historical activity, repeated
claims, missing provenance, collective equity/debt roles and an unresolved brief.
They create retained controlled PDFs and normal source/evidence/Claim records,
then invoke ordinary matching/composition/presentation owners. Fixture inputs
contain no expected result and remain EVALUATION_INPUT. No human review is
attested by the automated fixtures. Repeated claims do not establish authority.

Qualification: test_role_composition.py, test_matching_games.py and existing
professional narrative, matching, MM8 and Survey evaluation suites.
tools/verify_source_review_ui.py --propositions --matching-games exercises the
real forms, source-linked claims, composition, downloaded brief, eight games,
runtime observation and read-only Reload. The local human-curation exercise uses
a test identity; live automation does not assert human review.

Still incomplete: verified investor premise promotion, external discovery,
capital-amount allocation, partnership compatibility, interactive investor
relationship maps, the remaining investment games and PPT/PDF presentation
formats. The DOCX brief is a governed structured review, not a completed
institutional investment product. These limitations must remain explicit.
